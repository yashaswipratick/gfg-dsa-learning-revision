/*
==================== BINARY SEARCH CHEAT SHEET ====================

👉 Use binary search when:
   - Array is sorted
   - You need to search / optimize / find boundary

---------------------------------------------------------------
1. BASIC BINARY SEARCH (Find exact target)
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] == target) return mid;
    else if (arr[mid] < target) start = mid + 1;
    else end = mid - 1;
}
return -1;

---------------------------------------------------------------
2. FIRST OCCURRENCE (Lower Bound)
👉 First index where arr[i] >= target
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] < target) {
        start = mid + 1;
    } else {
        end = mid - 1; // move left
    }
}
// start = answer

---------------------------------------------------------------
3. LAST OCCURRENCE (Upper Bound)
👉 Last index where arr[i] <= target
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] <= target) {
        start = mid + 1;
    } else {
        end = mid - 1;
    }
}
// end = answer

---------------------------------------------------------------
4. FIRST ELEMENT GREATER THAN TARGET
👉 Smallest element > target (your problem)
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] <= target) {
        start = mid + 1;
    } else {
        end = mid - 1;
    }
}
// start = answer

// wrap-around case:
return arr[start % arr.length];

---------------------------------------------------------------
5. LAST ELEMENT SMALLER THAN TARGET
👉 Largest element < target
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] < target) {
        start = mid + 1;
    } else {
        end = mid - 1;
    }
}
// end = answer

---------------------------------------------------------------
6. SEARCH IN ROTATED SORTED ARRAY
---------------------------------------------------------------
while (start <= end) {
    int mid = start + (end - start) / 2;

    if (arr[mid] == target) return mid;

    // left half sorted
    if (arr[start] <= arr[mid]) {
        if (target >= arr[start] && target < arr[mid]) {
            end = mid - 1;
        } else {
            start = mid + 1;
        }
    }
    // right half sorted
    else {
        if (target > arr[mid] && target <= arr[end]) {
            start = mid + 1;
        } else {
            end = mid - 1;
        }
    }
}

---------------------------------------------------------------
🧠 KEY PATTERNS TO REMEMBER

1. “Find exact” → return mid
2. “First >= target” → move left (end = mid - 1)
3. “Last <= target” → move right (start = mid + 1)
4. Always think:
   👉 Are we eliminating left or right?

---------------------------------------------------------------
⚠️ COMMON MISTAKES

- Using (start + end) / 2 → overflow risk
- Infinite loops (wrong condition updates)
- Not handling edge cases (like wrap-around)

---------------------------------------------------------------
🎯 GOLDEN RULE

👉 Binary search is NOT about finding target
👉 It’s about shrinking the search space correctly
